# 瀏覽器與 Extension 速查（第八章）

## 內建（不是 Chrome 應用程式商店「擴充功能」）
- **Gemini in Chrome**：側欄摘要、Ask about this tab 等  
- **Auto browse** 等多為 Pro／Ultra，且有地區限制 → Free 主線可能不可用，標 Paid／之後補

## 熱門第三方（商店搜尋名為準；安裝前看權限與隱私）
| 名稱 | 典型用途 | 提醒 |
|---|---|---|
| Sider / DeepSider | 側欄多模型（可含 Gemini） | 對話可能經第三方；勿貼機密 |
| Monica | 側欄助理／寫作 | 同上 |
| AITOPIA | 彙整多 AI | 同上 |
| Gemini Chat Sidebar 類 | 專注 Gemini 側欄 | 確認開發者與權限 |
| NotebookLM／Gemini Notebook 匯入類 | 網頁→筆記本 | 地區與產品改名注意 |
| AI Exporter 類 | 匯出 Gemini 對話 | 核對是否寫入外站 |

## 使用者 Comet（Chromium）可對照的 AI 相關項（本機曾核實）
- Comet／comet-agent（內建助理）
- DeepSider™、NotebookLM Web Importer／Jetpack、YouTube→Notebook 類
- AI Exporter、GAS AI Companion、Manus AI Browser Operator、AI Selection Assistant、Retriever AI、Nanobrowser、iGenflow 等

## 實作原則
1. 主線仍在 **gemini.google.com 網頁**完成 CASE  
2. Extension＝加分路徑：加速摘要分頁、匯出、側欄  
3. **勿教破解、繞過付費牆或濫用 API**  
4. 安裝前閱讀權限：能否讀所有網站、能否改頁面
