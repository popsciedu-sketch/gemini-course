## 建議走讀順序（最短路徑）

1. 讀 `platforms-cheatsheet.md`＋`account-tiers-cheatsheet.md`（5 分）→ 設定裡睇自己用量。  
2. 用 `sample-brief.md`＋`sample-meeting-notes-raw.txt` 跑一輪整理 → 對 `sample-meeting-notes-cleaned.md`。  
3. 按 `sample-skill-instructions.md` 建成 `/museum-meeting-notes`，再只貼 raw 稿重跑。  
4. 有額度再試 `sample-deep-research-prompt.md`（先改計畫）。  
5. 產圖課用 `sample-image-prompt.txt`（英文備援句已附）。
