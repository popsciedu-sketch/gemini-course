# Gemini 使用教學（gemini-course）

繁體中文互動教材：Gemini 網頁／App 工作流（聊天、提示詞、Deep Research、Canvas、Gem、多模態、Live、產圖、Workspace、Notebook、連接與隱私）。

- 靜態 HTML／CSS／JS，進度存 localStorage
- 無聊天機器人、不連 Gemini API、無假截圖（僅 `.shot-slot` 預留）
- 非 Google 官方文件轉載；介面以線上為準

本地預覽：

```bash
cd gemini-course && python3 -m http.server 8080
```

GitHub Pages：倉庫根目錄即網站。
