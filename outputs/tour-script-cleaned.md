# 導賞稿整理結果（示範）

> 依 `materials/tour-script-force-energy.md` 整理。結構示範；你貼進 Gemini 的結果可不同。

## 12 分鐘家庭版流程
| 時間 | 環節 | 要點 |
|---|---|---|
| 0–1′ | 開場 | 力與能量＝身體記得住的轉換 |
| 1–5′ | 斜面滾球 | 高度→勢能→動能；質量固定 |
| 5–8′ | 彈簧 | 彈性勢能；安全提醒 |
| 8–11′ | 齒輪 | 速度與力氣交換 |
| 11–12′ | 收束三問 | 意外／改高度／回家找例子 |

## 說明牌白話建議
- 「勢能」→「因為位置（高度）而存著的能量」
- 「動能」→「因為在動而有的能量」

優先建立直觀，公式為加分。成品上牆前需人工核對。
