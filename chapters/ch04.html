第四章 · Canvas

全頁編輯器＋浮動聊天（不是左右 50/50）

現行 Canvas 以全頁預覽／編輯為主，聊天以浮動面板輔助。先寫短規格→最小版→一次一事迭代。

版面心智

本示範帳未見 Create 下拉。若你畫面有 Create（網頁／資訊圖／測驗等），請自行截圖對照；沒有就標「待補／學員自對照」，勿假裝一定有。

待補／學員自對照 · Create 下拉選單 若介面有 Create，展開並標選項；無則註記。
待補／學員自對照 · Create 轉換成品 完成一種轉換後截成品。

最小流程

  1. 短規格

    對象、篇幅、必須段落、禁區——一次講清。

  2. 最小版

    先要骨架，再加細節。

  3. 選段微調

    一次只改語氣或長度。

  4. 匯出

    常見 .md／雲端硬碟。
