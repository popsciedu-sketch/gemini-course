第四章 · Canvas

先規格，再最小版，再迭代

Canvas 是「邊對話邊改成品」的工作區：文件、簡報、小網頁、程式。不要一次超長 prompt 就收工——先規格／最小版，再一次改一類。

左右欄心智模型

  1. 開 Canvas

    輸入框工具列選 Canvas，用短規格描述要做什麼（類型、讀者、章節、語氣）。

  2. Preview／選取修改

    右側預覽。選一段再要求「短一點」「更正式」——比整篇重生成穩。

  3. Deep Research → Create

    研究報告可在 Canvas 裡用 Create 轉成網頁、資訊圖、測驗、語音概覽等（實際按鈕以介面為準）。

  4. 分享前檢查資料邊界

    公開連結可能讓他人看到或編輯相關內容。分享前確認沒有內部數字、個資、未公開策略。

概述：gemini.google/overview/canvas · Help：Canvas（日文）。

規格範例（開場用）

複製用請在 Canvas 做「一頁企劃摘要」（先最小版）。 讀者：部門主管，3 分鐘能讀完。 結構：背景 → 問題 → 方案三選項比較表 → 建議 → 風險。 約束：繁中；不捏造預算數字（沒有就標 TBD）；表格優先。 完成後等我指示再加細節，不要一次寫成十頁。

迭代口訣

  • 一次只改一類：結構／語氣／長度／視覺，不要同時全改。
  • 中文視覺輸出（資訊圖、簡報字）必人工看字形與斷行。
  • 匯出到 Google 簡報／文件後，再依公司模板微調。

Canvas 可做的類型

  • 文件：企劃、報告、講義——右側 Preview，選段微調。
  • 程式／小應用：描述功能 → 預覽 → 看程式碼／主控台（視介面）。
  • 簡報／網頁：在提示明講「做成簡報／單頁網站」；或用 Create 轉換。

從 Deep Research／文件按 Create

  1. 報告完成後

    在 Canvas 右上找 Create。

  2. 選產出

    常見選項：網頁、資訊圖、測驗 Quiz、語音摘要 Audio Overview；也可提示做成簡報或其他視覺。

  3. 人工驗收

    中文資訊圖必看字形；測驗題抽查對錯；語音當複習輔助，重要數字仍回文字來源。
