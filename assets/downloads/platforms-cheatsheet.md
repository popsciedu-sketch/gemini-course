# 網頁／桌面／手機差異速查

> 核實摘錄：2026-10-30｜課程 FACTS＋RESEARCH 補遺  
> 上課建議：先勾選「我主要用 □網頁 □桌面 □手機」，再對照本表選示範機。

---

## 總覽

| 表面 | 入口 | 最適合 | 課堂重點 |
|---|---|---|---|
| **網頁** | https://gemini.google.com | 長提示、Deep Research、Canvas、多檔、Skills 管理、文件預覽編輯（Docs／Sheets／簡報等） | **標準課室**；功能最齊 |
| **桌面 Mac** | https://gemini.google/desktop/ | Overlay、視窗上下文、系統聽寫、編程代理（Antigravity 等） | 快捷鍵 **Option+Space**（完整窗 Option+Shift+Space）；Apple Silicon＋較新 macOS |
| **桌面 Windows** | 同上 | Overlay＋完整工作區（聊天／產圖／接 Workspace） | 快捷鍵 **Alt+Space**；原生能力仍陸續追上 Mac |
| **手機 Android** | Gemini App | Live、相機、螢幕問答、裝置動作；可當主助理 | **Live／相機必用手機示範** |
| **手機 iOS** | Gemini App | Live、相機、文字／語音 | **不能**當系統級 Siri 替代；部分 Assistant 動作不可用 |
| **Workspace 側欄** | Gmail／Docs／Sheets／Slides／Drive 等 | 對眼前檔案改寫、摘要、插入 | **無**完整 Canvas／Deep Research；受 Admin 限制 |

---

## 必記差異（2026-10 補遺）

1. **Gemini Live**：官方 Help 仍寫暫時**不在網頁版**——課程「Live＋Camera」請用**手機 App**示範；網頁改做文字／Research／Canvas。  
   來源：https://support.google.com/gemini/answer/15274899  
2. **檔案預覽編輯**：PDF 網頁＋手機；Docs／Sheets／簡報等編輯**主要網頁**。  
   來源：https://blog.google/innovation-and-ai/products/gemini-app/edit-files-directly/  
3. **Skills**：可用於網頁、手機 App、Mac App（以 Help 當日為準）；用 `/技能名` 呼叫。  
4. **Connected Apps**（舊稱 Extensions）：連接 Gmail／Drive 等；因裝置／地區／Admin 而異。  
5. **公司／學校帳**：手機部分助理功能可能關閉。

---

## 三分鐘自測

| 我想示範… | 用邊個表面 |
|---|---|
| Deep Research／Canvas／長 prompt | 網頁（或完整桌面工作區） |
| Live 語音來回＋相機指物問答 | **手機** |
| 唔切瀏覽器、快捷鍵喚出助手 | 桌面 App |
| 改眼前一封 Gmail／一份 Docs | Workspace 側欄 |
